# IFC test fixtures

All files in this directory were written by hand (or generated by Arcus's own exporter from a
synthetic test model) for Arcus's automated tests. They contain no third-party content.

To the extent possible under law, the authors have waived all copyright and related or neighboring
rights to these fixtures (CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/).

| File | Purpose |
| --- | --- |
| `small-ifc4-mm.ifc` | IFC4, millimetre units: storeys, wall (IfcExtrudedAreaSolid + Axis + layer set usage), opening, door, slab with IfcIndexedPolyCurve profile, space, CSG block proxy, boolean clipping proxy. |
| `small-ifc2x3.ifc` | IFC2X3: IfcWallStandardCase, IfcFacetedBrep floor slab, IfcMappedItem furniture, non-ASCII names (`\X2\`), an IfcFlowSegment that must be kept as reference geometry. |
| `units-feet.ifc` | IFC4 with conversion-based FOOT/DEGREE units and a four-level placement chain. |
| `truncated.ifc` | The first 1400 bytes of `small-ifc4-mm.ifc` (truncated input). |
| `malformed.ifc` | Syntax error inside an instance. |
| `hostile-cycles.ifc` | Cyclic placements and mapped items, dangling references, absurd values, out-of-range indices. |
| `golden-ifc2x3.ifc`, `golden-ifc4.ifc` | Regression goldens produced by the exporter from the deterministic test model (see `GoldenTests.swift`; regenerate with `ARCUS_REGENERATE_IFC_GOLDENS=1`). |
